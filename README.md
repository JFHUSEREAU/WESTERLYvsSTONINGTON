# Westerly vs. Stonington

The website for the Westerly–Stonington Thanksgiving Day football rivalry (since 1911).

- `index.html` – the site
- `data.json` – every game, record and award (updated each December from the rivalry spreadsheet)
- `photos.json` + `photos/` – approved gallery photos
- `img/` – team logos

Hosted on Cloudflare Pages. No build step: the site is plain files.
